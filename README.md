# Tirth Rathod — Resume Website

A beginner-friendly HTML and CSS portfolio created for the Website Development Module 3 and Module 5 assignments.

## Files
- `index.html`: website content and sections
- `style.css`: all CSS styling
- `profile.jpg`: **add your own photograph with this exact filename**

## How to preview
Open `index.html` in your browser.

## How to publish to the existing GitHub repository
1. Open your original resume website repository on GitHub.
2. Upload or replace `index.html` and `style.css` in the repository root.
3. Add your photo named `profile.jpg` to the same folder.
4. Commit changes. Keep the same repository.
5. Under Settings > Pages, check that Pages is deployed from the correct branch and root folder.
6. Open the live site and check all sections, the photo, and mobile layout.

## Submission PDF
Create one PDF named `26121353_WD_MTProject.pdf` with the live website URL, repository URL, section descriptions and CSS improvements. Don't submit until the links are verified.
